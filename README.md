# PLP Python Week 4

This assignment practices Python functions, parameters, return values, and default parameters.

- `welcome.py` - Contains a welcome function that receives a name and returns a greeting.
- `toolbox.py` - Contains three functions: double, is_pass, and greet.

The hardest function to write was `greet` because it uses a default parameter for the greeting. I had to understand how Python uses "Hello" automatically when no greeting is provided.
